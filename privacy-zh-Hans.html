我们不收集你的学习数据

番茄学习计时器的核心功能完全在设备上运行，不需要账号。我们不收集、上传或出售你的任务名称、专注记录、成长、收藏或使用设置。应用不包含广告、分析、追踪或第三方统计 SDK，也不访问通讯录、相册、麦克风或位置。

记录保存在本机

任务、学习区间、计时状态、角色选择和设置保存在应用的本机存储中。锁屏、切换应用或重新打开时，番茄学习计时器使用已保存的时间校正计时。系统设备备份可能包含应用数据，是否备份由你的系统设置决定。

到点提醒与锁屏卡片

只有你开启到点提醒并允许系统通知后，番茄学习计时器才会安排专注或休息结束时的本地通知。锁屏计时卡片使用设备上的实时活动，默认关闭，默认不显示任务名称。开启显示任务名称后，附近的人可能在锁屏上看到它。你可以随时在番茄学习计时器设置中关闭这些功能，系统权限也可在系统设置中管理。

备份由你保管

保存 JSON 备份或导出 CSV 时，你自行选择保存位置或分享对象；番茄学习计时器不会将文件发送到开发者服务器。选择第三方云盘或分享服务后，文件由该服务按其政策处理。恢复备份只在本机校验和合并记录。备份可能包含任务名称，请妥善保管。

查看和删除

你可以在统计和成长页面查看记录，在设置中导出完整备份。移除锁屏卡片不会删除学习记录。使用系统的“删除 App”会清除应用本机数据；你保存到应用外的备份和系统备份需要自行另行删除。卸载前请先保存需要保留的数据。

适用人群与政策更新

番茄学习计时器是一款面向一般用户的学习计时工具，不提供医疗诊断、治疗或学习效果保证，也不提供社交内容。未成年人可在监护人指导下使用。若后续功能改变数据处理方式，我们会更新这份政策并在需要时征求同意。

联系开发者

如需咨询隐私或反馈问题，请使用 App Store 产品页面上的技术支持入口联系开发者。请不要发送不必要的任务内容或完整学习备份。你主动提供的支持信息仅用于理解和处理该次问题。

支持网站与反馈

此支持网站由 GitHub Pages 托管，与离线应用分别运行。GitHub 按其隐私声明处理访客 IP 地址等平台数据。页面不添加广告或统计脚本。通过问题页发布的反馈公开可见并由 GitHub 处理，请勿发布私人任务内容或完整备份。
