隱私政策

我們不收集你的學習資料

呆茄的核心功能完全在裝置上執行，不需要賬號。我們不收集、上傳或出售你的任務名稱、專注記錄、成長、收藏或使用設定。應用不包含廣告、分析、追蹤或第三方統計 SDK，也不訪問通訊錄、相簿、麥克風或位置。

記錄儲存在本機

任務、學習區間、計時狀態、角色選擇和設定儲存在應用的本機儲存中。鎖屏、切換應用或重新開啟時，呆茄使用已儲存的時間校正計時。系統裝置備份可能包含應用資料，是否備份由你的系統設定決定。

到點提醒與鎖屏卡片

只有你開啟到點提醒並允許系統通知後，呆茄才會安排專注或休息結束時的本地通知。鎖屏計時卡片使用裝置上的實時活動，預設關閉，預設不顯示任務名稱。開啟顯示任務名稱後，附近的人可能在鎖屏上看到它。你可以隨時在呆茄設定中關閉這些功能，系統許可權也可在系統設定中管理。

備份由你保管

儲存 JSON 備份或匯出 CSV 時，你自行選擇儲存位置或分享物件；呆茄不會將檔案傳送到開發者伺服器。選擇第三方雲盤或分享服務後，檔案由該服務按其政策處理。恢復備份只在本機校驗和合並記錄。備份可能包含任務名稱，請妥善保管。

檢視和刪除

你可以在統計和成長頁面檢視記錄，在設定中匯出完整備份。移除鎖屏卡片不會刪除學習記錄。使用系統的“刪除 App”會清除應用本機資料；你儲存到應用外的備份和系統備份需要自行另行刪除。解除安裝前請先儲存需要保留的資料。

適用人群與政策更新

呆茄是一款面向一般使用者的學習計時工具，不提供醫療診斷、治療或學習效果保證，也不提供社交內容。未成年人可在監護人指導下使用。若後續功能改變資料處理方式，我們會更新這份政策並在需要時徵求同意。

聯絡開發者

如需諮詢隱私或反饋問題，請使用 App Store 產品頁面上的技術支援入口聯絡開發者。請不要傳送不必要的任務內容或完整學習備份。你主動提供的支援資訊僅用於理解和處理該次問題。

支援網站與意見回饋

此支援網站由 GitHub Pages 託管，與離線應用分別執行。GitHub 按其隱私宣告處理訪客 IP 地址等平臺資料。頁面不新增廣告或統計指令碼。透過問題頁釋出的反饋公開可見並由 GitHub 處理，請勿釋出私人任務內容或完整備份。
